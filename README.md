## ✦ EASY GUI FAMILY

A collection of focused Windows interfaces that turn complex AI models and research projects into practical, self-contained workflows.

### TTS

**[Fish Audio Drama 3](https://github.com/Mixomo/Fish_Drama_3_Easy_GUI)**
Windows GUI for generating speech with Fish Audio Drama 3. It provides Single Inference, Dialogue Builder, saved voice references, optional reference transcription, and configurable text chunking. Inference uses CUDA or Vulkan GPU runtimes.

**[Qwen TTS Easy GUI](https://github.com/Mixomo/Qwen_TTS_Easy_GUI)**
A Windows-first application for Qwen3-TTS. It combines CustomVoice, VoiceDesign, zero-shot voice cloning, reusable Voice Library entries, single and multiple-reference conditioning, Dialogue Builder, Faster-Whisper transcription, project-based dataset preparation, Qwen-compatible Full SFT, PEFT/LoRA inference and CUDA-graph acceleration in one Gradio application.

**[XTTS-v2 Easy GUI](https://github.com/Mixomo/XTTS-V2-Easy-GUI)**
Windows-first Gradio GUI for Coqui XTTS-v2 with native inference, single/multi-reference Voice Library, language-aware chunking, project-based dataset preparation, automatic pronunciation/BPE enhancement, full GPT-encoder fine-tuning, prompted evaluation, TensorBoard monitoring and completion feedback.

**[CosyVoice3-Easy-GUI](https://github.com/Mixomo/CosyVoice3-Easy-GUI)**
A full Windows workflow for CosyVoice 3, combining zero-shot cloning, cross-lingual and instruct synthesis, reusable voice/instruction libraries, dialogue generation and experimental LoRA training.

**[IndexTTS-2.5-Easy-GUI](https://github.com/Mixomo/IndexTTS-2.5-Easy-GUI)**
A Windows interface for IndexTTS 2.5 focused on expressive voice cloning: reusable voices, independent emotion references, emotion vectors, natural-language emotion control, multilingual synthesis and dialogue generation.

**[FireRedTTS3-Easy-GUI](https://github.com/Mixomo/FireRedTTS3-Easy-GUI)**
An integrated FireRedTTS3 workspace covering much more than voice cloning: Voice Design, semantic speech editing, acoustic editing, multilingual synthesis, dialogue building and experimental LoRA training.

**[MOSS-TTS-Family-Easy-GUI](https://github.com/Mixomo/MOSS-TTS-Family-Easy-GUI)**
A broader MOSS-TTS workstation supporting multiple model generations, native multi-speaker dialogue, realtime TTS, voice generation, sound effects, long-form synthesis and both Transformers and llama.cpp CUDA inference.

**[Fish_audio_S2_Simple_GUI](https://github.com/Mixomo/Fish_audio_S2_Simple_GUI)**
A performance-oriented Fish Speech S2 Pro environment for Windows, pairing voice cloning and LoRA training with GGUF quantization, a custom C++ `s2.cpp` backend, CUDA/Vulkan acceleration and architecture-aware installation.

**[Higgs_Audio_TTS_Easy_GUI](https://github.com/Mixomo/Higgs_Audio_TTS_Easy_GUI)**
A practical Windows interface for Higgs Audio TTS, centered around expressive speech generation and multi-speaker dialogue workflows.

**[OmniVoice_Simple_GUI](https://github.com/Mixomo/OmniVoice_Simple_GUI)**
An OmniVoice workspace with voice libraries, dataset preparation, LoRA fine-tuning and inference, including Windows-specific Triton/Flex Attention patches and VRAM-aware training optimizations.

**[VoxCPM2_Simple_GUI](https://github.com/Mixomo/VoxCPM2_Simple_GUI)**
A Windows WebUI for VoxCPM voice cloning and fine-tuning, with dataset preparation, LoRA training, multi-speaker dialogue generation and accelerated inference.

### Image

**[Seed-VR-2.5-Easy-GUI](https://github.com/Mixomo/Seed-VR-2.5-Easy-GUI)**
A lightweight Windows interface for Seed-VR 2.5 image restoration and enhancement, designed to expose the model's image-focused workflow without the complexity of the underlying research environment.

### Music

**[XLance-MSR_Easy_Install](https://github.com/Mixomo/XLance-MSR_Easy_Install)**
A streamlined Windows installation workflow for XLance-MSR, making modern AI music source-separation models easier to set up and run locally.

## ✦ VST3 / AUDIO SOFTWARE

**[Dexed-TX816](https://github.com/Mixomo/Dexed-TX816)**
A Windows VST3 FM synthesizer rack inspired by the Yamaha TX816, combining multiple Dexed-based FM modules into a single playable instrument.

**[CalCurve](https://github.com/Mixomo/CalCurve)**
A headphone calibration and equalization tool built around measurement data, target curves and correction filters, designed for flexible multi-stage headphone correction workflows.

**[VST3 Bridge for AIMP](https://github.com/Mixomo/VST3_Bridge_For_AIMP/tree/main)**
VST3 Bridge for AIMP is a Windows DSP plug-in that hosts a single VST3 effect inside AIMP's DSP pipeline. It is intended for users who want to run a selected VST3 processor while playing audio through AIMP, including ASIO output.

## ✦ WINDOWS APPS

**[EqAPO64_with_VST3_support](https://github.com/Mixomo/EqAPO64_with_VST3_support)**
A reworked Windows build of Equalizer APO with native VST3 support and an expanded audio-processing workflow, bringing plugin-based processing directly into the system-wide APO environment.

**[Virtual-HDR-OSD-for-Windows-11](https://github.com/Mixomo/Virtual-HDR-OSD-for-Windows-11)**
A Windows 11 utility that provides an on-screen control layer for HDR workflows, designed to make display and HDR adjustments accessible without relying entirely on monitor hardware controls.
